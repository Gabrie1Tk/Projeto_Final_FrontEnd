Este repositório contém o código-fonte do projeto final do módulo de Front-End. Trata-se de um website estático desenvolvido para um portal/loja focada em artigos de corrida e divulgação de maratonas.

## Sobre o Projeto

O objetivo deste projeto foi aplicar conceitos fundamentais de desenvolvimento web, criando um site multipáginas com navegação intuitiva e layout estilizado. O site simula uma loja virtual especializada em ténis de corrida de alta performance e inclui secções informativas sobre eventos.

### Estrutura do Site
O projeto é composto pelas seguintes páginas:

- **`index.html`**: Página inicial (Home) com destaques e boas-vindas.
- **`produtos.html`**: Catálogo de ténis (ex: Adizero Adios Pro 3, Alphafly 3, etc.).
- **`corridas.html`**: Informações sobre eventos e percursos (ex: Corrida de São Silvestre).
- **`quem-somos.html`**: Página institucional sobre a empresa/projeto.
- **`trabalhe-conosco.html`**: Página de contacto/recrutamento.

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização, layout e design responsivo (arquivo `styles.css`).

## Como Rodar o Projeto

Como é um projeto estático (apenas HTML e CSS), não necessita de instalação de dependências ou servidores complexos.

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/Gabrie1Tk/Projeto_Final_FrontEnd.git](https://github.com/Gabrie1Tk/Projeto_Final_FrontEnd.git)
    ```
2.  **Acesse à pasta do projeto:**
    Navegue até o diretório onde os arquivos foram salvos.
3.  **Abra no navegador:**
    Dê um duplo clique no arquivo `index.html` ou clique com o botão direito e escolha "Abrir com" o seu navegador preferido (Chrome, Edge, Firefox).

> **Dica:** Se utilizar o VS Code, pode usar a extensão "Live Server" para visualizar as alterações em tempo real.
